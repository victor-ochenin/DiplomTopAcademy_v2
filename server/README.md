# Nodomia Server

RAG-сервер для образовательного расширения Nodomia. Обрабатывает вопросы пользователя по материалам курсов и проверяет код заданий.

Сервер использует Retrieval-Augmented Generation: запрос пользователя векторизуется, в ChromaDB ищутся релевантные фрагменты курсов, и LLM формирует ответ строго на их основе.

## Архитектура

```
POST /api/query  ─→  queryRag()
POST /api/check-code  ─→  checkCode()
       │
       ├── LLM: OpenRouter (instruct-модель + embedding)
       ├── Vector Store: ChromaDB (докер-контейнер)
       └── Web Fetcher: cheerio (скачивание документации)
```

## Компоненты

### `src/index.ts`

Точка входа. Hono-приложение с двумя роутами:

| Роут | Описание |
|------|----------|
| `POST /api/query` | Принимает вопрос и историю диалога. Возвращает ответ LLM, основанный на материалах курсов. |
| `POST /api/check-code` | Принимает код пользователя, условие задания и критерии. LLM оценивает корректность решения и возвращает passed + feedback. |

### `src/rag/`

| Файл | Назначение |
|------|-----------|
| `query.ts` | RAG-пайплайн: `queryRag` — векторный поиск + промпт + LLM. `checkCode` — отправка кода и критериев на LLM-проверку. |
| `vectorStore.ts` | Клиент ChromaDB. Инициализация индекса, вставка документов, поиск. Вычисление контрольной суммы (SHA-256) для отслеживания изменений в данных. |
| `embeddings.ts` | Кастомная функция эмбеддингов (`OpenRouterEmbeddingFunction`) — адаптер ChromaDB к OpenRouter API. |
| `webFetcher.ts` | Сбор документации с react.dev через cheerio. Разбивка страниц на чанки, загрузка по списку URL из конфига. |

### `data/`

| Путь | Назначение |
|------|-----------|
| `data/chroma/` | Персистентное хранилище ChromaDB. Контрольные суммы (`checksum.txt`, `web-checksum.txt`) для отслеживания изменений в курсах и веб-источниках. |
| `data/lessons/` | Копия данных уроков из extension. Синхронизируется при запуске. |
| `data/web-sources/react-docs.json` | Список URL документации react.dev для индексации в ChromaDB. |

### Данные сервера

Весь `data/` — рабочие данные, **в репозиторий не входят** (директория в `.gitignore`):

- `data/lessons/` — копия уроков из расширения (`../nodomia/src/data/lessons`), создаётся командой `npm run predev`;
- `data/web-sources/` — конфигурация источников для скрапинга (например, `react-docs.json`); в репо отсутствует, создаётся локально;
- `data/chroma/` — база ChromaDB, создаётся при запуске.

На сервере повторение уроков есть (копия при `predev`), но в репозитории их нет.

## Данные в векторном хранилище

ChromaDB содержит два типа документов:

1. **Материалы курсов** — JSON + Markdown из расширения. Загружаются с диска, разбиваются на чанки и векторизуются. Контрольная сумма определяет, нужно ли переиндексировать.
2. **Веб-документация** — страницы react.dev, скачанные через cheerio. URL и чанки настраиваются в `react-docs.json`. Отдельная контрольная сумма для веб-источников.

Поиск по векторному хранилищу возвращает топ-K релевантных чанков, которые подаются в промпт LLM как контекст.
