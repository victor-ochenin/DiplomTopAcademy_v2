# Что такое Vue.js?

Vue — это **прогрессивный фреймворк** для построения пользовательских интерфейсов.

## Что значит «прогрессивный»?

Vue можно внедрять постепенно:

- использовать как простую вставку на страницу для отдельного компонента;
- постепенно расширять до полноценного SPA (Single Page Application).

Вам не нужно переписывать всё приложение сразу — Vue подключается по мере роста проекта.

## Ключевые возможности

- **Декларативный рендеринг** — вы описываете, как должен выглядеть интерфейс при данных, а Vue обновляет DOM.
- **Компонентная модель** — интерфейс собирается из переиспользуемых компонентов.
- **Реактивность из коробки** — данные автоматически синхронизируются с представлением.

## Vue и React

И Vue, и React используют Virtual DOM и компоненты. Главные отличия:

- Vue использует **шаблоны** (HTML-подобный синтаксис), React — JSX.
- Реактивность Vue встроена в фреймворк, в React её добавляют хуки.

Vue часто выбирают за низкий порог входа и понятную структуру шаблонов.
