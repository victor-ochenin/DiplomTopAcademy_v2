# Создание первого проекта Vue

Самый простой способ создать проект Vue — официальный скэффолдер Vite.

## Создание проекта

```bash
npm create vue@latest my-app
```

Скрипт задаст несколько вопросов (TypeScript, Router, Pinia и т.д.) — для старта можно выбрать «Нет» везде.

## Структура проекта

```
my-app/
├── index.html          # точка входа в браузер
├── package.json        # зависимости и скрипты
├── vite.config.js      # конфигурация Vite
└── src/
    ├── main.js         # создаёт приложение Vue
    ├── App.vue         # корневой компонент
    └── components/     # компоненты приложения
```

- `index.html` — содержит `<div id="app">` и подключение `src/main.js`.
- `src/main.js` — создаёт экземпляр приложения и монтирует его в DOM.
- `src/App.vue` — корневой компонент, с которого начинается всё приложение.

## Запуск

Перейдите в созданную папку проекта и установите зависимости:

```bash
cd my-app
npm install
npm run dev
```

Vite поднимет сервер разработки (обычно на `http://localhost:5173`) с горячей перезагрузкой.
