# Однофайловые компоненты (SFC)

Single-File Component (SFC) — это способ описания компонента в одном файле с расширением `.vue`.

## Три блока SFC

```vue
<template>
  <p>Привет, {{ name }}!</p>
</template>

<script setup>
const name = 'Мир';
</script>

<style scoped>
p {
  color: green;
}
</style>
```

- `<template>` — разметка компонента.
- `<script setup>` — логика и данные (Composition API).
- `<style>` — стили компонента.

## Зачем это нужно?

- **Связанность** — разметка, логика и стили одного компонента лежат рядом.
- **Ограниченная изоляция** — стили с `scoped` в основном не «протекают» на другие компоненты.
- **Читаемость** — большие проекты проще навигировать.

## Scoped-стили

Атрибут `scoped` добавляет к каждому элементу уникальный атрибут `data-v-*`:

```vue
<style scoped>
h1 {
  color: red;
}
</style>
```

Стиль применяется только к элементам этого компонента. Важно одно исключение:
scoped-стиль родителя действует и на **корневой элемент** дочернего компонента
(но не на его потомков). Для глобальных стилей используют `:global()`, но в
основах он не нужен.
