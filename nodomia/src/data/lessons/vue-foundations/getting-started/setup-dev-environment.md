# Настройка окружения разработки

Чтобы начать работать с Vue, установите следующие инструменты.

## Node.js и npm

Vue-проекты собираются через Vite, а он требует Node.js.

1. Скачайте LTS-версию Node.js с официального сайта.
2. Проверьте установку:

```bash
node -v
npm -v
```

## Редактор кода: VS Code

VS Code — самый популярный редактор для Vue-разработки.

Установите расширение **Volar** (Vue Language Features):

- подсветка синтаксиса `.vue` файлов;
- автодополнение шаблонов, выражений и стилей;
- поддержка TypeScript.

## Браузер и DevTools

Для отладки установите **Vue Devtools** в браузер (Chrome/Firefox):

- инспектирует компоненты и их состояние;
- показывает реактивные данные;
- удобен для поиска проблем с рендерингом.

## Что дальше?
