# Реактивные объекты с reactive()

`reactive()` делает реактивным целый **объект**.

## Синтаксис

```vue
<script setup>
import { reactive } from 'vue';

const user = reactive({
  name: 'Иван',
  age: 25,
});
</script>
```

В отличие от `ref`, доступ к свойствам идёт напрямую, без `.value`:

```js
user.name = 'Пётр';
```

## В шаблоне

```vue
<template>
  <p>{{ user.name }}, {{ user.age }}</p>
</template>
```

## Ограничения reactive()

- Работает только с **объектами** (и массивами), не с примитивами.
- Нельзя заменять весь объект целиком: `user = { ... }` разорвёт реактивность.
- Для примитивов и замены целиком используйте `ref`.

## ref vs reactive

| Задача | Инструмент |
|---|---|
| Одно число/строка/boolean | `ref` |
| Объект, который частично мутируют | `reactive` |
| Нужно менять ссылку на объект целиком | `ref` |

Правило-подсказка: начинайте с `ref` — он покрывает почти все случаи.
