# Привязки атрибутов с v-bind

Интерполяция `{{ }}` работает только с текстом. Чтобы динамически задать **атрибут** элемента, используют директиву `v-bind`.

## Базовый синтаксис

```vue
<script setup>
const url = 'https://vuejs.org';
</script>

<template>
  <a v-bind:href="url">Документация</a>
</template>
```

`v-bind:href` связывает атрибут `href` со значением переменной `url`.

## Сокращение

Сокращённая форма — просто `:`:

```vue
<a :href="url">Документация</a>
```

Оба варианта эквивалентны. Сокращение используется чаще.

## Динамическое имя атрибута

Имя атрибута тоже может быть динамическим:

```vue
<a :[attrName]="value">Ссылка</a>
```

## Булевы атрибуты

Если значение `false` или `null`, Vue удаляет атрибут из элемента:

```vue
<button :disabled="isDisabled">Кнопка</button>
```

При `isDisabled = true` появится `disabled`, при `false` — исчезнет.
