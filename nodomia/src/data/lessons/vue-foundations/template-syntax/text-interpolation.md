# Текстовая интерполяция и выражения

Базовый способ вывести данные в шаблон Vue — **mustache**-синтаксис.

## Интерполяция

```vue
<script setup>
const message = 'Привет, Vue!';
</script>

<template>
  <p>{{ message }}</p>
</template>
```

`{{ message }}` подставляет текущее значение переменной и автоматически обновляется при её изменении.

## Выражения в интерполяции

Внутри фигурных скобок можно использовать любое JavaScript-выражение:

```vue
<p>{{ count + 1 }}</p>
<p>{{ name.toUpperCase() }}</p>
<p>{{ isActive ? 'Да' : 'Нет' }}</p>
```

## Ограничения

Vue поддерживает **только выражения**, а не инструкции:

- ✅ `{{ count + 1 }}`
- ✅ `{{ user.name }}`
- ❌ `{{ if (x) { ... } }}` — это оператор, а не выражение
- ❌ `{{ count++ }}` — нельзя мутировать состояние в шаблоне

Выражения должны быть простыми и без побочных эффектов.
