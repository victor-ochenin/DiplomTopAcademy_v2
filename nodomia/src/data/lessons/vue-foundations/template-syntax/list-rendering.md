# Рендеринг списков с v-for

Для вывода списков Vue использует директиву `v-for`.

## Массивы

```vue
<script setup>
const items = ['Яблоко', 'Груша', 'Слива'];
</script>

<template>
  <ul>
    <li v-for="item in items">{{ item }}</li>
  </ul>
</template>
```

## Индекс

Второй аргумент — индекс элемента:

```vue
<li v-for="(item, index) in items">
  {{ index }}: {{ item }}
</li>
```

## Объекты и диапазоны

`v-for` работает и с объектами:

```vue
<li v-for="(value, key) in user">{{ key }}: {{ value }}</li>
```

И с диапазонами чисел:

```vue
<li v-for="n in 10">{{ n }}</li>
```

## Атрибут key

Для стабильной идентификации элементов обязательно указывать `:key`:

```vue
<li v-for="item in items" :key="item.id">{{ item.title }}</li>
```

`key` помогает Vue эффективно обновлять список: элементы с одинаковыми ключами переиспользуются, а не пересоздаются. Без корректного `key` список может обновляться с багами (съезжает состояние, фокус, анимации).
