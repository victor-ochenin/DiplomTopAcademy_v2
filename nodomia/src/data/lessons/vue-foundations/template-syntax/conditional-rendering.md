# Условный рендеринг: v-if и v-show

Vue предоставляет две директивы для условного отображения элементов.

## v-if / v-else-if / v-else

Директива `v-if` полностью создаёт или удаляет элемент из DOM:

```vue
<script setup>
import { ref } from 'vue';

const isLoggedIn = ref(true);
</script>

<template>
  <p v-if="isLoggedIn">Добро пожаловать!</p>
  <p v-else>Войдите в аккаунт</p>
</template>
```

Цепочку можно продолжать через `v-else-if`:

```vue
<p v-if="score > 90">Отлично</p>
<p v-else-if="score > 60">Хорошо</p>
<p v-else>Попробуйте ещё раз</p>
```

## v-show

Директива `v-show` переключает CSS-свойство `display: none`, но **оставляет элемент в DOM**:

```vue
<p v-show="isVisible">Этот элемент всегда в DOM</p>
```

## Когда что использовать

| Ситуация | Директива |
|---|---|
| Элемент нужен редко или условия сложные | `v-if` |
| Элемент часто показывают/скрывают | `v-show` |
| Нужно условие с `v-else` | `v-if` |

`v-show` быстрее при частых переключениях, но элемент всегда существует в разметке и его стили загружаются всегда.
