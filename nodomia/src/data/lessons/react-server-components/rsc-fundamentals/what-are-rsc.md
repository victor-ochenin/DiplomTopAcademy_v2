# Что такое серверные компоненты?

Серверные компоненты (RSC) — компоненты, которые выполняются **исключительно на сервере**. Они не отправляют JavaScript-код в браузер.

## Ключевые особенности

- **Нулевой bundle-размер** — код серверного компонента никогда не попадает к клиенту
- **Прямой доступ к ресурсам** — база данных, файловая система, API-ключи
- **Автоматический streaming** — сервер отправляет результат по мере готовности

## Пример

```tsx
import db from './database';

async function Posts() {
  const posts = await db.query('SELECT * FROM posts ORDER BY created_at DESC');

  return (
    <ul>
      {posts.map((post) => (
        <li key={post.id}>
          <h2>{post.title}</h2>
          <p>{post.content.slice(0, 100)}...</p>
        </li>
      ))}
    </ul>
  );
}
```

## Что НЕ могут серверные компоненты

- Использовать хуки (`useState`, `useEffect`, `useContext`)
- Использовать браузерные API (`localStorage`, `window`, `document`)
- Обрабатывать события (`onClick`, `onSubmit`)
- Использовать кастомные хуки, зависящие от состояния

## Преимущества

- Меньше JS отправляется клиенту → быстрее загрузка
- Данные загружаются на сервере → нет водопадов запросов
- Чувствительные данные (токены, ключи) остаются на сервере
